The Controller Pak moves into the shared runtime, with N64Recomp-browser v0.257.0's renderer and runtime.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `GoinQuackersRecompiled-v0.1.15-windows-x64.zip` and run `GoinQuackersRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `GoinQuackersRecompiled-v0.1.15-linux-x64.tar.gz` and run `GoinQuackersRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 20 MiB, SHA-1 `e31a7567d408c890065029ba537f830765b17d94`): pick it with **Load ROM**, then **Start Game**.

**Changed:**

- The Controller Pak your game saves to is now the runtime's own, the one the other recompilations of the project share. It is the same file as before, `saves/controllerpak_1.mpk`, so a save made with an earlier release loads as it did.

These come with N64Recomp-browser v0.257.0's renderer and runtime.
