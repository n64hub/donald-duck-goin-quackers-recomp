An update to Donald Duck: Goin' Quackers Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Fixed:** built on the newest RT64: a framebuffer the game writes from the CPU, without drawing into it, no longer grows the renderer's video memory as the game runs (it grew about 20 MB a second in the game that showed it).

**Windows:** unzip `GoinQuackersRecompiled-v0.1.10-windows-x64.zip` and run `GoinQuackersRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `GoinQuackersRecompiled-v0.1.10-linux-x64.tar.gz` and run `GoinQuackersRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 20 MiB, SHA-1 `e31a7567d408c890065029ba537f830765b17d94`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** a whole playthrough from start to end, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/donald-duck-goin-quackers-recomp/issues).

The same game plays in a browser at [n64hub.com/goin-quackers](https://n64hub.com/goin-quackers/).
