The first release of Donald Duck: Goin' Quackers Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 20 MiB, SHA-1 `e31a7567d408c890065029ba537f830765b17d94`). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `GoinQuackersRecompiled-v0.1.0-windows-x64.zip` and run `GoinQuackersRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `GoinQuackersRecompiled-v0.1.0-linux-x64.tar.gz` and run `GoinQuackersRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the logos, the title and the language menu; the main menu and its save slots; a new game through the newscast to the world map; every level of the game's table, each loaded and drawn, the boss levels, the end map, the credits and the game over screen with them; the pause menu. Sound (the game's own audio code, recompiled), the game's Controller Pak saves kept across restarts, and keyboard and gamepad input.

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that plays as the console does:

- High resolution at the window's size, with anti-aliasing
- Smooth motion at the display's refresh rate, blended between the game's frames
- Widescreen: in a window wider than 4:3 the world reaches the window's edges and the HUD's counters sit at its sides; the spiral that closes between scenes and the stone plate the newscast opens behind cover the whole window; dialogue and the menus stay in the middle 4:3
- Keyboard and gamepad controls, rebindable

**Not checked yet:** a whole playthrough from start to end (every level has been loaded, but not played through to its exit, so expect the odd thing drawn wrong or a spot that hangs; reports are welcome on the [issues page](https://github.com/n64hub/donald-duck-goin-quackers-recomp/issues)), long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only).

The same game plays in a browser at [n64hub.com/goin-quackers](https://n64hub.com/goin-quackers/). The [README](https://github.com/n64hub/donald-duck-goin-quackers-recomp#readme) has how to build it yourself.
