A fix for Donald Duck: Goin' Quackers Recompiled, for Windows and Linux.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Fixed:** the game reaches its title screen and menus however long the launcher was open first. The game's clock counted the time spent in the launcher, so after a minute or two there the logos and the title screen ended at once, and the game went from one attract demo to the next: pressing Start only loaded another one. Now its clock starts when the game does, as on a console ([#7](https://github.com/n64hub/donald-duck-goin-quackers-recomp/issues/7)).

**Windows:** unzip `GoinQuackersRecompiled-v0.1.3-windows-x64.zip` and run `GoinQuackersRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `GoinQuackersRecompiled-v0.1.3-linux-x64.tar.gz` and run `GoinQuackersRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). You need your own ROM of the USA release (a big-endian `.z64` of 20 MiB, SHA-1 `e31a7567d408c890065029ba537f830765b17d94`): pick it with **Load ROM**, then **Start Game**.

**Not checked yet:** a whole playthrough from start to end, long play sessions, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/donald-duck-goin-quackers-recomp/issues).

The same game plays in a browser at [n64hub.com/goin-quackers](https://n64hub.com/goin-quackers/).
